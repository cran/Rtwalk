Reproducing Christen & Fox (2010)

This vignette is precomputed: its code is run when the package is developed, not when it is installed, because some experiments take a few minutes. The full source is in vignettes/reproducing_christen_fox.Rmd.orig.

This document checks the implementation in Rtwalk against the article that introduced the t-walk:

Christen, J. A. and Fox, C. (2010). A general purpose sampling algorithm for continuous distributions (the t-walk). Bayesian Analysis, 5(2), 263–282. doi:10.1214/10-BA603

It is organized by the sections of the paper. Each section first states what the paper specifies and then verifies it numerically. The last section discusses the one point where our numbers differ from the article: some of the reported acceptance rates.

library(Rtwalk)
set.seed(2010)

1. Where each piece of the paper lives in the code

The t-walk maintains two points, \(x\) and \(x'\), and is a Metropolis–Hastings sampler on the product space with target \(f(x, x') = \pi(x)\pi(x')\). At each step only one of the points moves: the proposal is \((x, h(x', x))\) or \((h(x, x'), x')\), each with probability 1/2 (equation 1 of the paper). The function \(h\) is one of four moves.

Paper Content Rtwalk
Sec. 2, eq. (1) update one of the two points twalk_move()
Sec. 2 random subset of coordinates, \(np = \min(n, n_1)\) p_phi = min(n, n1) / n

Sec. 2.2, eq. (2) Traverse move \(h_t\), \(\psi_t\), Jacobian \(\beta^{n_I - 2}\) kernel_traverse(), simulate_beta()

These R functions form a reference implementation that follows the paper literally. Sampling is done by a compiled C++ translation of it, and the test suite checks that both produce the same chains draw by draw. The defaults of twalk_control() are those of Section 2.5:

2. The proposal distributions

The Traverse move (Section 2.2, Figure 1)

The step \(\beta\) of the Traverse move has density

\[\psi_t(\beta) = \frac{a_t - 1}{2a_t}(a_t + 1)\beta^{a_t}\,I_{(0,1]}(\beta) + \frac{a_t + 1}{2a_t}(a_t - 1)\beta^{-a_t}\,I_{(1,\infty)}(\beta),\]

which satisfies \(\psi_t(1/\beta) = \psi_t(\beta)\), and is simulated with equation (2). The paper sets \(a_t = 6\), “giving \(P(\beta < 2) \approx 0.98\)”.

psi_t <- function(beta, at = 6) {
  ifelse(beta <= 1,
         (at - 1) / (2 * at) * (at + 1) * beta^at,
         (at + 1) / (2 * at) * (at - 1) * beta^(-at))
}

betas <- replicate(1e5, Rtwalk:::simulate_beta(6))

The Walk move (Section 2.1)

The Walk move uses \(\alpha_j\) with density \(\psi_w(\alpha) \propto 1/\sqrt{1 + \alpha}\) on \([-a_w/(1 + a_w), a_w]\), simulated by inversion as \(\alpha = \frac{a_w}{1 + a_w}(-1 + 2u + a_w u^2)\). This choice makes the proposal symmetric, so the acceptance probability is the ratio of target densities.

aw <- 1.5
u <- runif(1e5)
alpha <- aw / (1 + aw) * (-1 + 2 * u + aw * u^2)
k <- 1 / (2 * (sqrt(1 + aw) - 1 / sqrt(1 + aw)))
hist(alpha, breaks = 100, freq = FALSE, col = "grey85", border = "white",
     main = expression(psi[w](alpha) ~ "with" ~ a[w] == 1.5), xlab = expression(alpha))
curve(k / sqrt(1 + x), from = -aw / (1 + aw), to = aw, add = TRUE, lwd = 2, col = "#C73E1D")

The Hop and Blow moves (Section 2.3)

For the Hop move, \(h_h(x, x')_j = x_j + \sigma z_j / 3\) with \(\sigma = \max_{I_j = 1} |x_j - x'_j|\); for the Blow move, \(h_b(x, x')_j = x'_j + \sigma z_j\). The paper gives their densities in closed form; the package’s helpers return \(-\log g\), which we compare with the formulas of the paper on an example where only some coordinates move:

x <- c(0.3, -1, 2, 5); xp <- c(1, 0.5, -2, 4)
phi <- c(TRUE, FALSE, TRUE, TRUE); n_I <- sum(phi)
sigma <- max(abs(x - xp)[phi])

y <- x; y[phi] <- x[phi] + c(0.2, -0.4, 0.1)            # a Hop proposal
g_h <- (2 * pi)^(-n_I / 2) * 3^n_I / sigma^n_I *
  exp(-9 / (2 * sigma^2) * sum((y - x)[phi]^2))
c(paper = -log(g_h), Rtwalk = Rtwalk:::log_density_hop(n_I, phi, y, x, xp))
#>    paper   Rtwalk 
#> 3.678924 3.678924

y <- x; y[phi] <- xp[phi] + c(0.2, -0.4, 0.1)           # a Blow proposal
g_b <- (2 * pi)^(-n_I / 2) / sigma^n_I *
  exp(-1 / (2 * sigma^2) * sum((y - xp)[phi]^2))
c(paper = -log(g_b), Rtwalk = Rtwalk:::log_density_blow(n_I, phi, y, x, xp))

3. Invariance (Section 2.6, Theorem 1)

Theorem 1 states that the t-walk is invariant under \(\phi(z) = az + b\) with scalar \(a \neq 0\): running it on \(\lambda(z) = |a|^{-n}\pi(\phi^{-1}(z))\) from \((\phi(x_0), \phi(x'_0))\) is equivalent to running it on \(\pi\) from \((x_0, x'_0)\) and transforming the chain with \(\phi\). For \(a > 0\) every move commutes with \(\phi\) draw by draw, so with the same random numbers the two chains must coincide up to rounding error, which is a sharp test of the implementation. (For \(a < 0\) the Hop and Blow moves add \(|a|\sigma z\) instead of \(a\sigma z\); the transition kernels still agree because \(z\) is symmetric, but the paths no longer coincide.)

log_pi <- function(x) {
  mu <- c(0.5, -1, 2); s <- c(1, 2, 0.7)
  -0.5 * sum(((x - mu) / s)^2)
}
a <- 4.25; b <- c(10, -3, 7)
log_lambda <- function(z) log_pi((z - b) / a) - length(z) * log(abs(a))

x0 <- c(-1, 0, 1); xp0 <- c(2, -2, 3)
set.seed(1)
chain_pi <- twalk(log_pi, 5000, x0, xp0, show_progress = FALSE)
set.seed(1)
chain_lambda <- twalk(log_lambda, 5000, a * x0 + b, a * xp0 + b, show_progress = FALSE)

image_of_pi <- sweep(a * chain_pi$samples, 2, b, "+")
max(abs(chain_lambda$samples - image_of_pi))
#> [1] 6.215473e-11
identical(chain_lambda$kernel_statistics, chain_pi$kernel_statistics)
#> [1] TRUE

dnorm2 <- function(z, mu, S) {
  # bivariate normal density for a vector or a matrix of points (rows)
  z <- matrix(z, ncol = 2)
  d <- sweep(z, 2, mu)
  Q <- rowSums((d %*% solve(S)) * d)
  exp(-Q / 2) / (2 * pi * sqrt(det(S)))
}

responsibility_2 <- function(z) {
  # posterior probability that z comes from the second component; its
  # expectation is the weight of that component, 0.3
  w2 <- 0.3 * dnorm2(z, c(-3, 10), S2)
  w2 / (w2 + 0.7 * dnorm2(z, c(6, 0), S1))
}

set.seed(5)

5. Comparison with optimally tuned Metropolis (Section 4, Figure 5)

Section 4 compares the t-walk with random-walk Metropolis (RWM) on the targets of Roberts & Rosenthal (2001), \(\pi(x) = \prod_{j=1}^n C_j\, g(C_j x_j)\) with \(g\) the standard normal density, and

  • model 0: \(C_j = 10\);
  • model 1: \(C_j = 1\);
  • model 2: \(C_1 = 2\) and \(C_j = 1\) for \(j \geq 2\);
  • model 3: \(C_1 = 1\) and \(C_j \sim \mathrm{Exp}(1)\).

Efficiency is measured by the integrated autocorrelation time (IAT) of \(x_1\) divided by the dimension. RWM uses a Gaussian proposal tuned on model 1: standard deviation \(2.38/\sqrt{n}\) (“correct rescaling”, dashed lines in the paper), or \(2.38/\sqrt{10}\) for every \(n\) (“fixed scaling”, dotted lines). The same RWM is applied to all models, while the t-walk is used with its defaults. We start both samplers at draws from the target, discard 10% of each run as burn-in, and estimate the IAT with Geyer’s initial monotone sequence (calculate_diagnostics() reports it as IAT).

rwm_x1 <- function(log_target, x0, step_sd, n_iter) {
  x <- x0
  lp <- log_target(x)
  out <- numeric(n_iter)
  for (i in seq_len(n_iter)) {
    y <- x + step_sd * rnorm(length(x))
    lp_y <- log_target(y)
    if (log(runif(1)) < lp_y - lp) {
      x <- y
      lp <- lp_y
    }
    out[i] <- x[1]
  }
  out
}

iat_x1 <- function(x1) {
  x1 <- x1[-seq_len(floor(0.1 * length(x1)))]
  length(x1) / Rtwalk:::.ess_basic(matrix(x1, ncol = 1))
}

The qualitative conclusions of the paper are reproduced:

  • the IAT of the t-walk grows roughly linearly with the dimension, so IAT/n stays bounded (“in most cases below 15” in the paper) for all four models, with the same sampler and no tuning;
  • RWM with the correct rescaling is better for models 1 and 2, for which it was tuned, and competitive for model 3; but the same sampler fails on model 0, whose scale is ten times smaller: beyond \(n = 5\) it accepts no proposal after burn-in, so its IAT is undefined and its curves stop;
  • without rescaling (fixed scaling), RWM degrades quickly with the dimension.

Because the t-walk is invariant to the scale of the target (Section 3), models 0 and 1 are the same problem for it: their curves coincide up to Monte Carlo error.

Some rates agree with the paper and others are lower. The modes of equation (4) are not given in the paper, so those rates are not directly comparable, but the bivariate normal and the two targets of Figure 3 are fully specified. We investigated this discrepancy carefully:

  • Every formula of Section 2 is implemented as written (Sections 1–3 of this vignette), the sampler is exactly invariant as stated by Theorem 1, and it recovers the exact moments of the targets in Section 4.

  • We compared the code with the original R implementation by the first author (Rtwalk 1.8.0, archived on CRAN in 2015). In two dimensions all coordinates are updated at every step, and the two implementations differ only in the density of the Hop move: version 1.8.0 divides \(\sigma\) by three and then also applies the factors \(3^{n_I}\) and \(9/(2\sigma^2)\) of the paper, which uses the undivided \(\sigma\). The Hop move is chosen in 0.82% of the iterations, so this cannot explain differences of several percentage points. Version 1.8.0 also reports as “acceptance ratio” the average fraction of coordinates moved per iteration, which in two dimensions equals the acceptance rate.

  • We then ran version 1.8.0 itself on the three fully specified targets, with the same starting points and run lengths (mean of three runs each; this code is not part of the package, so the numbers are quoted here rather than computed):

    Fig. 3(a), mixture about 45% 27.0% 24.9%
    Fig. 3(b), Rosenbrock about 13% 7.7% 8.9%

    The two implementations agree within the run-to-run variability (single runs on the mixture ranged from 22% to 29%), and both are below the published rates.

The published rates therefore appear to come from a different version of the program or from settings not described in the paper, and not from the implementation of the algorithm; the remaining evidence shows that the sampler targets the correct distributions.

7. What is not reproduced

The radiocarbon age–depth model of Section 3.2 (dimension 71) depends on the calibration curve and on the EngXV data set, which are not distributed with the paper; it is not reproduced here.
